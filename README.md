# Chaos Sudoku SAT

Projeto da disciplina de Lógica para Ciência da Computação.

O objetivo é formalizar o problema Chaos Sudoku em Lógica Proposicional,
gerar instâncias no formato DIMACS CNF e resolvê-las utilizando um SAT solver.

## Estrutura inicial

- `gerador.py`: gerador das fórmulas CNF;
- `instancias/`: arquivos de entrada do Chaos Sudoku;
- `tests/`: testes automatizados.
